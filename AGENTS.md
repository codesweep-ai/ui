# Working in this repo

This file routes; it holds no knowledge of its own. The docs it points at are
authoritative. When one covers what you need, open it rather than inferring the
answer from the code. When nothing covers it, say so instead of guessing.

- [README.md](README.md) · what this package is, and the shortest way in.
- [INSTALL.md](INSTALL.md) · getting it, and the setup it needs once.
- [MANUAL.md](MANUAL.md) · what the package exports, and how the exports behave.
- [CATALOG.md](CATALOG.md) · every component and pattern, indexed by intent.
  Search this before building any UI. It is generated: edit the frontmatter
  under `components/` and `patterns/` instead.
- [DESIGN_SYSTEM_SPEC.md](DESIGN_SYSTEM_SPEC.md) · what the behaviour and the
  tokens must be. A change starts here.
- [CONTRIBUTING.md](CONTRIBUTING.md) · conventions, and the gates a change has
  to pass. Read it before your first change.
